## 名稱差異

TCMAX 與 `units/*.html` 是兩套不同譯名，對照表以 **TCMAX 名稱** 為主鍵：

| TCMAX | units 頁面 |
| --- | --- |
| 狙擊者 | 狙擊手 |
| 歌利亞 | 哥利亞 |
| 醫護兵 | 醫療兵 |
| 搜索者 | 搜尋者 |
| 雕堡車 | 碉堡車 |
| 氣墊掠奪者 | 戰艦控甲者 |
| 輕型摩托車 | 輕型摩托 |

另有三個 TCMAX 兵種在 `units/` 找不到對應名稱，暫留空白：**執法者**、**安諾爾**、**輕裝甲車**（`units/` 有 `executor`、`sweeper`、`light_cannon`，但中文名不同，需人工確認）。
